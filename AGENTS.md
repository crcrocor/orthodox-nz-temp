# orthodox-nz-temp — guide for coding agents

Temporary static site for orthodox.nz (stage 0, task 008 in crcrocor/orthodox-nz, decision 0004 there): the website of the New Zealand Deanery of the Russian Orthodox Church Outside of Russia, published by the trust CC42458 (Church of the Resurrection of Christ Russian Orthodox Church Abroad Trust, the Auckland parish), which needs a real site on its own domain for Apple Developer and Google for Nonprofits. Its content is the old Auckland parish site orthodox.net.nz plus a few new pages. The Wagtail portal in crcrocor/orthodox-nz replaces it later; keep this repository small and easy to retire.

## People and authority
- Developers: Fr Alexander (Claude Code, main language: Russian) and Fr Pavel (Codex, main language: English). Talk to them in their main language. Everything in the repo is in English; site content is in the page's language.
- Content, money, people, brand and anything public need the blessing of Fr Vladimir Boikov (rector); some things need Archbishop George. If a change needs a blessing, stop and write "needs blessing: …". Never decide it yourself.
- Keep the status of facts visible: decided / proposed / idea. Write "(planned)" for things that don't exist yet and "(hypothesis)" for unverified causes.

## Public repository
- Everything here is public. Commit only what was already on orthodox.net.nz or what has been approved for publication.
- Never read, print or commit secrets. No forms, accounts or personal data on the site.

## Commands
- `uv run scripts/mirror.py` — fetch orthodox.net.nz (network, manual; raw cache in `.cache/mirror/`) and regenerate the mirrored pages in `content/pages/` and the files in `static/`.
- `uv run scripts/build.py` — render `content/pages/` with `templates/base.html` into `dist/` (offline).
- `uv run scripts/check.py` — build plus every check, then lists all `TODO(content)` and `needs blessing:` markers. CI runs the same command; it is the only proof that the site is done.
- Preview: `python3 -m http.server -d dist`.

## Map
- `site.toml` — menu, footer and every page: path, kind (`mirror` regenerated by the mirror, `frozen` seeded once and then edited by hand, `local` written by hand), source, optional `h1`, `h1_ru`, `description`, `description_ru`. A page's `<title>` is its `<h1>`.
- `old_paths.txt` — every path the site has ever had; the mirror only adds to it, the check requires each one.
- `content/pages/` page bodies (English), `content/pages/ru/` Russian versions · `templates/` the one page template · `static/` CSS, files and images (old paths kept) · `scripts/corrections.py` fixes applied to mirrored pages · `.github/workflows/pages.yml` deploy.

## Workflow
- Until the custom domain is connected, work directly in `main`. After that, only through pull requests.
- Evidence before claims: say "done" or "works" only with fresh output of `uv run scripts/check.py` (or a screenshot) taken after the last change. Otherwise write "not verified".
- Make the smallest change that meets the task; follow the nearest existing pattern; no new dependency without the developer's OK.
- Keep old paths (`schedule.html`, `files/…`, `article/…`) working: the portal will redirect to them later.
- Links are relative, so the site works both at crcrocor.github.io/orthodox-nz-temp/ and at orthodox.nz.

## Content rules
- Never invent facts about the parish, clergy, services, people or amounts. Write `<!-- TODO(content): what is needed -->`. Here TODO and `needs blessing:` markers are hidden HTML comments, unlike the portal's dev site, because this site is public; `scripts/check.py` prints them all.
- Facts about the trust come only from the Charities Register (CC42458, CC33927), quoted as written there.
- Money is "donation" / "пожертвование" — never "price", "payment", "оплата", "цена".
- No politics, geopolitics or inter-jurisdictional topics.
- Languages: English is the default at the old paths, Russian lives under `ru/`, and a switch in the header leads to the same page in the other language. Hand-made pages have a Russian version in `content/pages/ru/<path>`, linking as seen from the English page; mirrored pages stay bilingual as on the old site in both versions (an exception to the portal's "one page — one language" rule). `scripts/build.py` marks the language of mixed text; never mix languages in new text.
- Church titles and terms follow «Православная энциклопедия»; English is New Zealand English.
- People in photos only with consent (photos already on orthodox.net.nz may stay); never present AI-generated images as real.

## Frontend rules
- Must work and read well in Chrome 109, Firefox ESR 115 and Safari 15.6, and on a phone.
- No third-party requests at runtime: no Google Fonts, CDNs, analytics, embeds or external images. External `<a href>` links are fine.
- No JS frameworks; no JS at all unless needed. Per page: JS ≤ 50 KB gzip, CSS ≤ 40 KB gzip.
- Neutral and temporary: system fonts, calm colours, no generic "AI look" (gradients, cards, pills, icon tiles) and no church kitsch (navy and gold, fake gilding, decorative вязь, icons as decoration).
